# serialport-napi-rs

NAPI addon for `serialport-rs` via `tokio-serial`.

> [!IMPORTANT]
> This is a temporary repository for evaluation purposes. See https://github.com/serialport/serialport-rs/issues/373

## Develop requirements

> Initially created from https://napi.rs/docs/cli/new (template source: https://github.com/napi-rs/package-template)

- Install the latest `Rust`
- Install `Node.js` - see `engines.node` field of `package.json` for currently supported versions
- Install `yarn` - see `packageManager` field of `package.json` for currently supported version

## Test in local

- yarn
- yarn build
- yarn test
